# Headout Partner API

> Headout is a global experiences marketplace for tours, attractions, events and activities. Its public Partner API lets affiliates and resellers browse the catalog by city and language, pull live inventory and pricing, and place bookings through a two-step create-then-capture flow. Auth is a Headout-Auth API key (pk_ production / tk_ sandbox); versioned by URI path under /api/public/.

## Endpoints
- GET /api/public/v2/products — list products for a city
- GET /api/public/v2/categories — list categories
- GET /api/public/v2/collections — list collections
- GET /api/public/v2/subcategories — list subcategories
- GET /api/public/v1/inventory/list-by/variant — inventory & pricing
- GET /api/public/v1/booking, GET /booking/{id}, POST /booking, PUT /booking/{id} — booking flow
